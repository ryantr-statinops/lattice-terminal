# Portfolio feature

Holdings spot BTC/ETH nhập thủ công hoặc CSV, lưu localStorage trên thiết bị hiện tại. Import kiểm tra asset/decimal và chỉ áp dụng cả batch nếu mọi dòng hợp lệ. P&L hiển thị từ fixture; tổng định giá được ẩn khi thiếu giá. Chưa có sync server/account, ledger giao dịch hay exchange trading keys.
