# Model Lab — evaluation proposal

**Trạng thái:** deferred outside the first MVP; this page does not define an active experiment or portfolio-backtest contract.

Any future model evaluation must use an approved point-in-time dataset, freeze configuration before holdout evaluation, report data coverage and assumptions, and compare reproducibly against explicit baselines. No performance or profitability claim is supported by the current mock UI.

V1 portfolio backtesting is specified separately in [Portfolio](../07-portfolio/README.md) and requires its own Vietnam-market, accounting, cost and fill-model decisions.
