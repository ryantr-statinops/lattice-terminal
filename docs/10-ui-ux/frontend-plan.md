# Frontend implementation

The [terminal redesign](terminal-redesign.md) is implemented as local commits on main, without push. [Review report](terminal-review.md) records exact verification, commit history, screenshots and limitations.

React/Vite/Router/Query/Tailwind and the existing routes/layout remain. Shared theme/UI/feature layers provide compact controls, semantic tables, async dialogs, explicit loading/error states and dark-only Appearance. Fonts are packaged for offline Vietnamese use. Research/Backtest/Strategy continue to share presentation with separate execution contracts and no file tabs.

Keyboard interactions include scoped Save/Run shortcuts, file tree navigation and bounded persistent pane resizing. Native prompts have been replaced with dialogs. Richer statistical reports, new watchlist tools, approved live-data integrations and full mobile layouts remain separate work.
