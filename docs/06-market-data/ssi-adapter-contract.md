# SSI adapter / Offline contract

SSI FastConnect Data is the only SSI product used by the market-data connector; FastConnect Trading is separate and has no enabled order routes. The local app has credential-to-Parquet paths for the HOSE equity catalogue using `SecuritiesDetails`, plus separate HOSE and HNX equity daily candles using `DailyOhlc`. Each request remains blocked unless its matching SourceGate scope is explicitly approved. **No SSI account has been tested and no production access or data rights are approved.** Intraday bars, other instrument classes and streaming are not connected. Synthetic fixtures remain the only enabled source for simulation.

SourceGate separates documented/access-tested/rights-confirmed/approved. A bounded probe needs separate authorization, entitlement/terms references, endpoint/field/purpose/range/quota limits, expiration and safe secrets. It can collect access evidence before production approval, without granting retention/display/export/research rights. No probe was executed.

The catalogue transport binds requests and normalized fields to one exact capability and endpoint. It validates pages and publishes an immutable snapshot only after `store` authorization; Market catalogue reads separately require `display`. The implementation is offline-testable, but access, rights, units, instrument lifecycle, service quota and retention expiry still require account-specific evidence. Extend only one documented dataset/capability at a time. No browser/log credentials. Offline authorization methods do not perform network calls.
